# Agent SDKs example: the refund agent, with and without the SDK

Source: `examples/sdk/refund-agent/` in the repository — one scripted support-agent
scenario implemented twice per language: [Python](python-agent-sdk.md)
(`without_sdk.py` / `with_sdk.py`) and [Java](java-agent-sdk.md)
(`WithoutSdk` / `WithSdk`). Unlike the [Spring AI example](java-agent-sdk-example.md)
it needs no model, no API keys and no running platform — the point is what the
governance pipeline does to the same tool calls.
