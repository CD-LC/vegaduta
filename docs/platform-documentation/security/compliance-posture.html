Certification statement
The open-source VegaDūta software carries no certification: it is not SOC 2, ISO/IEC 42001, ISO 27001, HIPAA or any other attested product, and this page makes no GDPR, DPDP or other compliance claim. Compliance is a property of a deployment and its operator. The controls below are mechanisms you can build a program on; an auditor has not tested them.

1. Framework mapping

FrameworkHow the code relates
SOC 2 (Security, Availability, Confidentiality)Most CC6/CC7/CC8 technical controls below have a code artifact. Privacy and Processing Integrity criteria are not addressed specifically.
ISO/IEC 42001 (AI management system)Human-oversight, guardrail, audit and kill-switch mechanisms exist; the management-system parts (risk register, roles, reviews) are organisational and out of scope for the code.
India DPDPThe software supports DPDP-oriented controls: an optional notice and consent step with a consent record, purpose tags, retention periods with a nightly purge, per-contact export and erasure, and an audit-event export with a breach runbook (section 2). They are engineering controls with documented limits, not a statement that any deployment complies; lawful basis, notice wording, processor agreements, children's data and the legal reading are the operator's and counsel's. See DPDP obligations and controls.
GDPRCode has a data-subject erasure path and an informational residency field (below); lawful basis, notices, DPAs and processor agreements are the operator's responsibility.

Convention: implemented means an artifact exists in code or config; policy / gap means the operator must supply it.

3. Gaps and operator responsibilities

ItemState
Periodic access reviewOperator policy; the code provides audit logs and role listings only
Incident response planOperator policy; see Observability and Rollback & Recovery for technical triage
Backup and restoreDocumented pg_dumpall procedure for Compose and optional Windows helper scripts; CNPG or managed-Postgres backups on Kubernetes. Scheduling and a tested DR drill are the operator's job (Backup & Restore)
Vendor and model-provider reviewGap: no subprocessor list, DPAs or model cards ship with the project
Dependency and CVE scanning in CICodeQL on pull requests, pushes to main and weekly; dependency review and gitleaks inside CI; OpenSSF Scorecard weekly. Container image CVE scanning of your running deployment is the operator's job.
Central audit-log retention / SIEMGap: app logs, Loki and Grafana only (profile observability)
Business continuity / RTO-RPO targetsOperator decision; the Compose tiers are single-host, and core runs one API replica until the Helm replicaReadiness flags are all true
Data residencyDataResidencyRegion is informational only: it records a declared jurisdiction and does not route or move data. One Postgres instance per deployment.
Erasure completenessDoes not cover graph-memory entities, or LLM/tool call logs that quote a subject's text; there is tension with log-retention needs that needs a legal decision. No UI for erasure.
Guardrail effectivenessSource describes the pattern implementation as modest and disclaims solving prompt injection or DLP; guardrails are configured per agent
