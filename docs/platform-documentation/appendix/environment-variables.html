Environment Variable Reference

Names, purpose, non-secret defaults and consumers for the variables that configure core, the compose stack, and the Next.js frontends. Secret-bearing variables carry a secret badge and no value — by design, and no .env, .env.local or .env.production* file was opened to write this page.

Sources read
core/.env.example, deploy/compose/.env.example, web/.env.local.example, core/app-config/src/main/resources/application*.yml, web/Dockerfile, web-admin/Dockerfile, deploy/compose/docker-compose.yml, deploy/compose/docker-compose.domain.yml.
Completeness
core's application.yml exposes roughly 200 placeholders. The tables list every operationally relevant group; the exhaustive list is the ${NAME:default} placeholders in that file (see the last section). Compose has additional per-service variables not in .env.example that were not enumerated.
Environment
Docker Compose reads deploy/compose/.env (generated by scripts/vegaduta secrets); Helm reads chart values and Kubernetes Secrets. Localhost defaults below are for local development only.
Secrets and the rules that bite
  • APP_ENCRYPTION_KEY must be identical everywhere core boots (deploy/compose/.env, core/.env.local, your Kubernetes Secret). A different value makes every stored provider key and channel secret undecryptable; rotation needs a decrypt/re-encrypt migration. APP_ENCRYPTION_KEY_PREVIOUS is set only during a deliberate rotation window.
  • The issuer core validates must be exactly the one Keycloak stamps (PUBLIC_AUTH_URL/realms/agentic-ai); any other accepted issuer goes in KEYCLOAK_ADDITIONAL_ISSUERS. A mismatch 401s every token — see ADR-0005.
  • NEXT_PUBLIC_* build args are optional: empty means nothing is baked and the runtime environment decides. Never bake a localhost URL into an image you deploy — see ADR-0007.
  • LLM provider keys, Twilio credentials and MCP credentials are not env vars: they are BYOK, entered in the console and stored encrypted per tenant (core/.env.example header).

3. web and web-admin (build-time)

The Dockerfiles declare the NEXT_PUBLIC_* values as optional build args. Empty (the default) bakes nothing and the runtime environment decides; Compose and the Helm charts supply them at runtime (deploy/helm/README.md). A value you do bake is compiled into the browser bundle and cannot be changed without a rebuild.
