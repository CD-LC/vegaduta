Command Reference (A–Z)

Every command below appears verbatim, or with only placeholder generalisation (<sha>, <service>), in deploy/README.md, a script header, the Makefile, or a workflow. Entries are grouped by executable, alphabetically. Nothing here was executed while writing this page.

Scope
Operator, deploy, CI and developer commands. Not a Spring or Next.js manual.
Deployments
Self-hosted with Docker Compose (scripts/vegaduta, make) or Helm (deploy/helm). Do not confuse environments when copying a command.
Verification
Command text was checked against the cited file. It does not mean the command was run or is safe on your machine.
Careful on a live stack
Avoid host reboots and docker compose down (especially with -v) on a stack people depend on, unless you mean to take it offline. A hung service is evidence to collect (logs, container states, memory) before you restart anything. Teardown of the ephemeral CI stack in .github/workflows/e2e.yml runs on a throwaway runner, not a real environment.

Conventions and cross-links

  • Pull requests run CI (CI OK) and Static gates; tags run release.yml. See CI/CD Pipelines.
  • Pin release versions (VEGADUTA_VERSION), never latest; upgrade with scripts/vegaduta upgrade --version X.Y.Z.
  • Ports and service names: Ports & Service Matrix. Variables: Environment Variables.
  • Not documented in the repository: a single canonical list of Maven module goals.
