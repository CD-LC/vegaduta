API Surface Overview

Base URL
http://localhost:8080 locally; https://api.<your-domain> behind the Compose domain overlay or a Helm ingress. Identity provider: http://localhost:8180 or https://auth.<your-domain>.
Style
JSON over HTTPS REST, Spring MVC controllers in core/*; streaming endpoints use text/event-stream.
Auth
Keycloak-issued bearer JWT by default; a small, explicit set of paths use other credentials. See Authentication & Authorization.
Scale
207 @RestController classes under core/**/src/main/java (counted by source scan, 2026-09-26). Not a generated OpenAPI spec: none exists in the repository.
How to read this page
Base paths and controller class names below were extracted from the @RequestMapping annotations in source. Per-endpoint verbs, request and response bodies are documented only on the pages where the controller was read in full (Streaming, Webhooks, Developer API). For every other area consult the controller named in the table.

Conventions

  • Tenancy. Every authenticated request runs inside a tenant taken from the JWT tenant_id claim (TenantContextFilter); there is no tenant parameter in URLs. Schema-per-tenant isolation is described in Data Architecture & Tenancy.
  • CORS. Configured in WebConfig from app.web.allowed-origins; X-Session-Id and Content-Disposition are exposed response headers.
  • Security headers. Core is a pure JSON API: CSP default-src 'none'; frame-ancestors 'none', strict-origin-when-cross-origin referrer policy, restrictive permissions policy (SecurityConfig).
  • Errors. Mapped centrally by GlobalExceptionHandler (core/app); the full status-code catalogue is not reproduced here.
  • Session correlation. Agent chat returns the session id in the X-Session-Id response header.

Deployment shape

Specific controllers are gated by Spring profiles: security (JWT resource server, billing, admin), mcpserver (/mcp, /api/dev/v1), and the fail-closed default !insecure security chain. Profile behaviour and the split into app/worker/jobs entry points is covered in System Architecture.
