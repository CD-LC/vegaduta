Searches the public web and returns ranked results with titles, URLs and snippets. Use this to research a topic, find sources, look up current events, news, prices, documentation or facts you do not know, or to DISCOVER a URL you can then open with fetch_web_page. You CAN search the internet through this tool - never claim you cannot. Search first, then fetch the most promising result for full text.
