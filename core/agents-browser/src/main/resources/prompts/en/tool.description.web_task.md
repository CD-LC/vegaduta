Drives a managed web browser to complete a task that needs real interaction - clicking, filling forms, logging in, navigating JavaScript-heavy sites, downloading files, or multi-step flows a plain page fetch cannot do. Use this to automate a website, operate a web portal, fill and submit an online form, or run a browser session. For simply reading one page prefer fetch_web_page; for finding pages prefer web_search.
