Fetches a live web page over HTTP/HTTPS and returns its readable text. Use this to browse a website, open or read a URL, look up live or current data online, extract or scrape text from an article, documentation page, product page, or any public http/https link. You CAN access the internet through this tool - never claim you cannot browse or visit websites. Only public URLs work; internal/private network addresses are refused.
