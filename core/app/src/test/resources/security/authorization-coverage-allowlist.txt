#   HANDLER  the controller or service checks access (owner, EDITOR/RUNNER/VIEWER grant, ...)
#   MEMBER   meant for any member: the caller's own data, or a metered member feature
#   FIX      a weakness the review found in the handler's own check, still to be fixed;
#            the number of FIX lines may only go down (MAX_FIX_ENTRIES)
# Prefer a SecurityConfig rule or @PreAuthorize to a new line here. A new line needs the same
# review: say what checks access, and where.
