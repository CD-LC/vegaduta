# Async hops reviewed as tenant-safe without TenantScope / TenantScopedFlux / the
# com.agenticai.core.security.concurrent factory (TenantAwareExecutors, TenantAwareSchedulers; ADR-0024).
#
# Every executor in core now comes from that factory (RawExecutorBanRulesTest), so most hops listed
# here already carry the submitter's tenant; they stay listed because the hand-off goes through a field
# typed ExecutorService/Executor, which this call-site rule cannot trace back to the factory.
#
# Read by AsyncHopTenantScopeRulesTest. One line per top-level class:
#     fully.qualified.ClassName | why every unwrapped hop in this class is safe
# A class belongs here only if each flagged hand-off in it (executor submit/execute/schedule,
# CompletableFuture *Async stage, Reactor subscribeOn/publishOn/interval/delay, raw Thread.start,
# @Async) either carries the tenant by hand (TenantContext set on the worker from data captured on the
# originating thread, always restored or cleared in finally; or an explicit tenant id/schema passed as
# data), or touches no tenant-schema table (control_plane-qualified SQL, Redis, HTTP, timers).
# Do NOT add a class here to silence the test for new code: capture a TenantScope on the originating
# thread and re-apply it on the worker. An entry whose class no longer has an unwrapped hop fails the
# test; delete it. The entry exempts the whole class, so keep reasons specific and review a second hop
# added to a listed class by hand.
