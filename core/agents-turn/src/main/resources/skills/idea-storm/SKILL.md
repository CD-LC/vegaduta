# Idea storm

Quantity first, judgement second. Never mix the two in the same pass.

## Diverge

Produce twenty or more ideas before judging any. Push beyond the obvious by
rotating through lenses, and say which lens each batch used:

- **Invert** - what would make this worst? Flip each answer.
- **SCAMPER** - substitute, combine, adapt, modify, put to another use,
  eliminate, reverse.
- **Random input** - pair the problem with an unrelated object or industry
  and force a connection.
- **Constraint** - what if it had to cost nothing, take one day, or work
  with no screen?
- **Audience swap** - how would a child, an expert, or a competitor see it?

Ideas are one line each. Include at least three that feel slightly too
strange; those are the useful ones to react to.

## Converge

1. Cluster the list into four to six themes.
2. Shortlist five with a one-line reason each, balancing novelty and
   feasibility.
3. For the top two, state the riskiest assumption and the cheapest
   experiment (under a day) that would test it.

## Rules

- Ask one question about the goal and audience if they are unclear;
  otherwise start immediately.
- For names and taglines, check the shortlist for awkward meanings and
  sound-alikes, and warn that availability (domains, trademarks) is not
  something you can verify.
- Do not present borrowed lines or brands as original. If an idea closely
  echoes something famous, say so.
- Offer another round with a different lens rather than a longer list from
  the same one.
