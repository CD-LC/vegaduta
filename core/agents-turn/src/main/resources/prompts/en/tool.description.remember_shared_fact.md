Saves a fact, preference, or correction about the current user so EVERY agent on this team can recall it, not just you - use this for facts genuinely useful across agents (e.g. "this customer's account is on the Enterprise plan", "prefers to be called by their first name"). For something only relevant to your own conversations with this user, use remember_fact instead.
