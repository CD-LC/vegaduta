# core values reference

Generated by [helm-docs](https://github.com/norwoodj/helm-docs) from `values.yaml`; do not edit by hand
(`deploy/helm/scripts/gen-docs.sh`). Per-component keys (`core.*`, `web.*`, ...) are documented in each
component chart's `values.yaml` under `deploy/helm/charts/<name>/`.
