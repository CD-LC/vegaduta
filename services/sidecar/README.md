# sidecar

The ML helper service (FastAPI, port 8001). Core and the voice agent call it over the internal network for the
work that needs Python ML libraries: embeddings, reranking, document text extraction (with OCR), speech to text,
text to speech, captions and video rendering. It is not on the chat hot path of a turn that needs none of these.

| | |
|---|---|
| Image | `services/sidecar/Dockerfile`, runs as the unprivileged user `sidecar`, `EXPOSE 8001` |
| Compose | service `sidecar`: on in Full, compose profile `rag` in Lite (`scripts/vegaduta up --lite --profile rag`) |
| Helm | `deploy/helm/charts/sidecar` |
| Auth | header `X-Internal-Token` equal to `SIDECAR_SHARED_SECRET` (compared in constant time), on every endpoint except `/health`. Without the secret every other endpoint answers 503. `SIDECAR_AUTH_REQUIRED=false` turns auth off for bare local development only; never set it on a deployment |
| Health | `GET /health` answers `{"status": "ok", "service": "sidecar"}` without credentials |
| Docs | the interactive API docs are off on purpose (the service is published on a host port) |

## Endpoints

| Route | Purpose |
|---|---|
| `POST /embed`, `POST /embed-query` | chunk and embed a text; embed one query |
| `POST /rerank` | cross-encoder reranking of search candidates |
| `POST /extract` | text extraction from documents and images (OCR through Tesseract) |
| `POST /transcribe` | speech to text (Whisper) |
| `POST /tts` | text to speech through Sarvam (needs `SARVAM_API_KEY`) |
| `POST /captions` | captions for a narration, from a local Whisper pass |
| `POST /render`, `GET /render/{job_id}`, `GET /render/{job_id}/artifact/{kind}` | start a video render (202), poll it, fetch the artifact |

When the bounded inference queues stay full past their timeout the service answers 503 so the caller can retry.

## Configuration

The tuning variables (queue timeouts, concurrency, Whisper workers, render limits, Sarvam limits, binaries) and
their defaults are in [Service environment](../../docs/configuration.md#service-environment). Compose passes
`SIDECAR_SHARED_SECRET` (generated by `scripts/vegaduta secrets`) and the provider keys; see
`deploy/compose/.env.example`.

## Develop

```bash
cd services/sidecar
pip install -r requirements.txt -r requirements-dev.txt
SIDECAR_AUTH_REQUIRED=false uvicorn app.main:app --port 8001   # local only, no auth
python -m pytest tests/ -q
ruff check .
```

Dependencies are locked with `services/lock-requirements.sh sidecar`.
