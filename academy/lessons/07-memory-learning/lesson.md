# Ep 7 — Memory & learning

**Length** ~3.5 min · **Level** everyone · **Renders to** `ep07-memory-learning.mp4`

Memory is what you tell the platform; learning is what it earns. Both are
human-readable, editable and gated — nothing silently persists.

## Coverage

- `/memory` — your notes, learned facts, per-assistant shared-memory switch
- `/skills` — packaged expertise, playground try-it hand-off
- `/skills/library` — learned-skill review queue, .zip import

## Click path

| Step | Where | What happens |
|---|---|---|
| Your memory | `/memory` | Real state: notes count, learned-facts count, assistants-with-access `0/3` |
| Share to an assistant | `/memory` → "Choose assistants" | Notes only enter chats with shared-memory-on assistants |
| Try a skill | `/skills` → "Play a story" | Opens Playground with a prompt naming the skill |
| Review learned skills | `/skills/library` | "Pending review" — agent-proposed skills do nothing until approved |

## Mental model

- **Notes** = facts you write once; they follow the assistant toggle.
- **Learned facts** = corrections the platform picked up; visible here.
- **Skills** = task-shaped instruction packs; learned drafts arrive
  *Pending review* and are inert until a human approves.
- Export & erase is one click — memory is auditable by design.
