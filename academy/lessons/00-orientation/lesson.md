# Ep 0 — The map (orientation)

**Length** ~4 min · **Level** everyone · **Renders to** `ep00-orientation.mp4`

The VegaDūta console has a lot of controls because it covers a whole
lifecycle. There are only four jobs the interface does for you, and every
screen belongs to one of them:

1. **BUILD** — author things: agents, workflows, skills, apps.
2. **CONNECT** — wire those things to the world: tools, MCP servers,
   channels, integrations.
3. **TEST & MONITOR** — prove it works: quality evals, turn replays,
   audit.
4. **OPERATE & ADMINISTER** — cost, health, access, policies.

## The scenes

| Screen | What it is | The Ledger |
|---|---|---|
| `/assistant` | Talk to the platform itself | Ask it to build/run/explain anything |
| `/agents` | Your staff — instructions, model, budget, tools | Editor-in-Chief is born here |
| `/workflows` | Assembly line of steps on a trigger/schedule | The production pipeline |
| `/tools` | Integrations & MCP catalog | Web search + Composio's 1000+ apps |
| `/knowledge` | Reference library, semantic retrieval | Style guide + source archives |
| `/admin/guardrails` | Output policies — claims, PII, spend | The editor's red pen |
| `/agents/quality` | Golden sets, scored runs, replay | Fact-checking before print |
| `/usage` | What happened, what it cost | Cost per edition |
